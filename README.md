# Wesley Deng — Academic Website

Static academic website published with GitHub Pages.

## Edit content

- `index.html`: homepage, biography, news and CV link
- `research.html`: papers, publications, abstracts and figures
- `teaching.html`: courses and teaching feedback
- `assets/`: images and public CV PDF

Edit the relevant file using GitHub’s pencil button and commit changes to the publishing branch. Pages redeploys after the commit. Keep filenames and links consistent. The CV file is the public version without telephone numbers or references.

## Publication

GitHub Pages serves the repository root. The `.nojekyll` file preserves the plain HTML/CSS/JavaScript site without a theme or build conversion.
